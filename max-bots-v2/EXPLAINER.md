# Explainer: лендинг `max-bots-v2` («Боты в MAX»)

Короткий разбор того, что было сделано: новый одностраничный лендинг для услуги «чат-боты и мини-приложения в мессенджере MAX». Один файл `index.html`, без сборки, светлый дизайн в духе Planes. Документ написан так, чтобы его мог прочитать и новичок, и тот, кто уже знаком с фронтендом.

> [!NOTE]
> Превью после мёржа: **https://hundredgold.github.io/sites/max-bots-v2/**
> Файл лежит в репозитории `hundredgold/sites`, папка `max-bots-v2/`.

## Контекст

Если коротко: лендинг — это одна веб-страница, задача которой убедить посетителя сделать одно действие. Здесь действие — открыть живого бота в MAX и/или написать Данилу.

> [!TIP]
> **Zero-build (без сборки)** — значит, что весь сайт умещается в один файл `index.html`: разметка, стили внутри `<style>` и скрипт внутри `<script>`. Нет ни npm, ни React, ни Tailwind CDN. Файл открывается двойным кликом и работает даже без интернета (кроме подгрузки шрифтов, для которых прописаны запасные). Этот абзац можно пропустить, если вы это и так знаете.

В репозитории `sites` уже было две версии этой услуги: тёмная (`max-bots`, коммит `8dbf707`) и светлая в стиле Planes (`max-planes`, коммит `d840140`). Новая задача — не править старое, а собрать с нуля отдельную папку `max-bots-v2` со светлым дизайном и строгой структурой из ТЗ. Так старые версии остаются нетронутыми, а новую можно показывать по отдельной ссылке.

## Интуиция

Вся страница держится на трёх простых идеях.

**Первая — токены дизайна.** Цвета, радиусы и шрифты заданы один раз в `:root` как CSS-переменные. Хотите перекрасить акцент во всём макете — меняете две строки, а не сто.

```css
:root{
  --accent-a:#4a86ff;   /* синий */
  --accent-b:#7c5cff;   /* фиолетовый */
  --grad:linear-gradient(135deg,var(--accent-a),var(--accent-b));
}
```

**Вторая — акцент точечно.** Фон белый, типографика крупная и чёрная, а сине-фиолетовый градиент появляется редко: одно слово в заголовке («работаете»), активная кнопка, маркеры списков, цифры. Именно редкость делает акцент заметным.

**Третья — один тёмный блок.** На всей светлой странице есть ровно одна тёмная вставка — макет чата с ботом в герое. Контраст притягивает взгляд именно туда, где показан продукт.

Появление секций при прокрутке работает по принципу «спящей» секции: пока блок за пределами экрана, он прозрачный и чуть смещён вниз; как только въезжает в кадр — проявляется. Наблюдатель отмечает блок один раз и перестаёт за ним следить.

## Код

Файл читается сверху вниз как рассказ. Разберём по группам.

**1. Голова документа.** `lang="ru"`, `charset`, `viewport`, SEO- и OG-теги, подключение Google Fonts (Inter + JetBrains Mono) с `preconnect`. В каждом `font-family` прописаны системные запасные шрифты, поэтому офлайн страница не «ломается».

**2. Токены и базовые стили.** Блок `:root` задаёт палитру, радиусы, ширину контейнера и шрифтовые стеки. Дальше — сброс отступов, плавная прокрутка, видимый фокус для доступности и утилиты `.wrap`, `.eyebrow`, `.btn`, `.grad-text`.

**3. Шапка.** Липкая, полупрозрачная, с размытием фона:

```css
header.site{
  position:sticky; top:0; z-index:50;
  background:rgba(255,255,255,.72);
  backdrop-filter:saturate(180%) blur(14px);
  border-bottom:1px solid var(--line);
}
```

Ссылки навигации скрываются на мобильном (`@media(max-width:760px){ .nav-links{display:none} }`), а кнопка «Открыть бота» остаётся всегда.

**4. Герой и тёмный чат.** Слева — надзаголовок с пульсирующей точкой, H1 с градиентным словом, подзаголовок и две кнопки. Справа — тот самый тёмный блок: макет диалога (заявка в УК → адрес → «Заявка №1047 принята»). Весь макет помечен `role="img"` с осмысленным `aria-label`, а внутренние реплики скрыты от скринридера через `aria-hidden`, чтобы он не читал «пузыри» по одному.

**5. Смысловые секции.** Закон (светлая лавандовая карточка с акцентной градиентной левой границей), «Что умеет» (4 карточки с номерами и SVG-иконками), живое демо (центр, крупная моноширинная ссылка на бота), «Как работаем» (4 шага с вертикальной линией), цены (3 карточки, средняя выделена рамкой и бейджем «Популярное»), контакты (две колонки с кликабельными `tel:`/`mailto:`/ссылками на бота) и подвал.

**6. Скрипт.** Вся логика — один `IntersectionObserver`. Если пользователь попросил меньше движения или в браузере нет наблюдателя, все блоки сразу показываются:

```js
var reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
if (reduce || !('IntersectionObserver' in window)) {
  els.forEach(function(el){ el.classList.add('in'); });
  return;
}
```

**7. Адаптив и доступность.** Три брейкпоинта (900 / 760 / 480 px): сетки сворачиваются в одну колонку, карточки цен складываются стопкой, выделенный тариф поднимается наверх. Блок `@media(prefers-reduced-motion:reduce)` глушит все анимации и переходы. У секций `scroll-margin-top:88px`, чтобы заголовок не прятался под липкой шапкой.

## Проверка

Проверял через Playwright (headless Chromium) и обычным grep по коду.

- **Скриншоты** на 1280px (герой, закон, «что умеет», демо, цены, контакты) и на 390px (герой, карточки, контакты) — приложены к сообщению в чате / лежат в выгрузке сессии.
- **Переполнение на 390px:** `scrollWidth === clientWidth` (390 = 390) — горизонтальной прокрутки нет.
- **Консоль:** единственные ошибки — неудачная загрузка Google Fonts, потому что в песочнице нет интернета. Это ожидаемо, запасные шрифты подхватываются. Своих JS-ошибок нет.
- **Якоря:** после перехода по `#features` и `#pricing` верх секции встаёт ровно на 88px от верха окна — `scroll-margin-top` работает, заголовок не уходит под шапку.
- **Ссылки:** все 5 ссылок на бота имеют `target="_blank"` и `rel="noopener"`; телефон — `tel:+79012826132`, почта — `mailto:bendikdanicx@yandex.ru`.
- **Reduced-motion:** в контексте с `reduced_motion:"reduce"` ни один блок `.reveal` не остаётся скрытым.
- **Запрещённые слова:** grep по «штраф / надзор / инспекц / санкц / более N клиентов / команда профессионалов / инновацион / гарантией качества / отзыв» — пусто. Слово «проверка» встречается один раз и только как функция счётчиков, не в блоке про закон.

> [!IMPORTANT]
> **Как проверить вручную:** откройте `max-bots-v2/index.html` двойным кликом. Пройдите по всем пунктам меню — заголовки должны быть видны под шапкой. Нажмите «Потыкать демо» — бот открывается в новой вкладке. Сузьте окно до ~390px — ничего не выезжает вбок. Включите «Reduce motion» в системе и обновите — плавные появления выключатся.

## Альтернативы

**Альтернатива 1. Собрать на фреймворке (React/Vite) или через Tailwind CDN.**

| Плюсы | Минусы |
| --- | --- |
| Готовые утилиты и компоненты | Не открывается двойным кликом, нужна сборка/CDN |
| Привычный DX при росте проекта | Лишние килобайты и зависимость от интернета |
| | Прямо противоречит требованию «zero-build, один файл» |

**Альтернатива 2. Оставить тёмную тему из прошлой версии.**

| Плюсы | Минусы |
| --- | --- |
| Уже существует, можно переиспользовать | ТЗ прямо требует светлый дизайн в стиле Planes |
| Тёмный фон эффектно смотрится в вебе | Хуже читается при печати и в дневном свете |
| | Теряется контраст «один тёмный блок на светлом» |

# Северный контур

Демонстрационный сайт для портфолио. Откройте `index.html` в браузере. В блоке проектов нажмите «Запросить смету», выберите регион и нажмите «Проверить заявку». В окне появится пример карточки для менеджера с выбранным домом. Сценарий работает локально, контакт условный, внешней отправки в почту или CRM нет.

Названия и характеристики проектов условные. Фотографии служат иллюстрациями. Файлы хранятся вместе со страницей, загрузка внешних ресурсов при просмотре не требуется.
